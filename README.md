# JCD Creator

**JCD Creator** превращает картинку в японский кроссворд и сохраняет его
в файл `.jcd`.

## Что делает программа

- загружает изображение (JPG, PNG, BMP, GIF);
- накладывает сетку с нужным числом колонок и строк;
- автоматически распознаёт заполненные клетки и подбирает цвета;
- позволяет поправить результат вручную;
- сохраняет готовый кроссворд в файл `.jcd`.

## Как пользоваться

1. Запустите `JCD Creator\JcdCreator.exe`.
2. Нажмите **«Открыть изображение...»** и выберите картинку.
3. При необходимости измените число **колонок** и **строк**, подвиньте
   рамку или растяните её за края и углы.
4. Нажмите **«Заполнить»**. Программа сама определит порог (по методу Оцу)
   и раскрасит клетки.
5. Выберите цвет в палитре **«Цвет кисти»** и поправьте клетки щелчком мыши.
   Повторный щелчок тем же цветом очищает клетку; белый цвет работает как
   ластик.
6. Нажмите **«Сохранить .jcd...»** и выберите место для файла.

## Требования

- Windows 7/8/10/11;
- .NET Framework 4.x (в Windows 8 и новее уже установлен).

## Исходный код

Исходники находятся в папке `src`. Собрать программу можно запуском
`src\build.cmd` — готовый exe появится в папке `JCD Creator`.
